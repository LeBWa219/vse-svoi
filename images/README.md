# Изображения для сайта «Все свои»

В этом файле — инструкция, куда класть картинки для каждого блока сайта.

## Структура

```
public/images/
├── partners/      ← Логотипы партнёров (Яндекс, Флит, Бери Заряд)
├── services/      ← Фото для карточек услуг
├── news/          ← Фото для карточек новостей
├── vacancies/     ← Фото для карточек вакансий
└── steps/         ← Фото для шагов «Как мы работаем»
```

## Как подставить картинку

1. Положи файл в нужную папку (например, `public/images/news/1.jpg`)
2. Открой соответствующий файл данных:
   - Новости → `src/data/news.js`
   - Услуги → `src/data/content.js`
   - Вакансии → `src/data/vacancies.js`
   - Шаги → `src/data/content.js`
3. Найди нужную карточку и впиши путь в поле `image`:

```js
{
  id: 1,
  title: '...',
  image: '/images/news/1.jpg',   ← вот так
}
```

## Если поле image пустое

В карточке автоматически покажется заглушка с иконкой и подписью «Место для фото».
Сайт не сломается — просто будет ждать картинку.

## Требования к картинкам

- **Формат:** JPG или PNG
- **Имена файлов:** только латиница, цифры, дефисы (например, `courier-1.jpg`, `office-team.jpg`)
- **Размеры (рекомендация):**
  - Новости: 800×600 px
  - Услуги: 600×400 px
  - Вакансии: 600×400 px
  - Шаги: 400×300 px

## Где что использовать

| Блок | Папка | Поле в данных |
|---|---|---|
| Новости | `/images/news/` | `news[].image` |
| Услуги (заказчикам) | `/images/services/` | `servicesContent.client.items[].image` |
| Услуги (исполнителям) | `/images/services/` | `servicesContent.performer.items[].image` |
| Вакансии | `/images/vacancies/` | `vacancies[].image` |
| Шаги (заказчикам) | `/images/steps/` | `stepsContent.client.steps[].image` |
| Шаги (исполнителям) | `/images/steps/` | `stepsContent.performer.steps[].image` |
